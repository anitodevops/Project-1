# Steps for Build Phase 

## Step 1: Clone the Source Code from Git Repository

#### Clone the Source code repository

  `git clone https://github.com/anithaambrose/E-commerce.git`

#### Initialize git repo.

  ```
  cd devops-build
  git init
  ```
*Note:
Ensure the cloned repo with  /build or /dist folder contains static files and index.html.*
